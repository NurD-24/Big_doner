# Big Doner: сайт + админ панель

Тек Node.js 18+ керек (npm install КЕРЕК ЕМЕС).

## Іске қосу
Windows: start.bat файлын екі рет басыңыз. Mac/Linux: терминалда ./start.sh

Немесе қолмен:
    ADMIN_PASSWORD=өзіңіздің_құпиясөз node server.js

- Клиент сайты: http://localhost:3000
- Админ панель: http://localhost:3000/admin
(ADMIN_PASSWORD көрсетпесеңіз, құпиясөз "admin123" болады. Міндетті түрде ауыстырыңыз!)
Порт өзгерту: PORT=8080

## Қалай жұмыс істейді
- Админ мәзірді, комбоны, бағаны, суретті, филиалды өзгертіп "Сайтқа сақтау" басады, ашық тұрған клиент беттері бірден жаңарады.
- Клиент тапсырыс бергенде админ панельде бірден шығады (дыбыспен). Админ статус ауыстырады (Қабылданды / Дайындалуда / Жолда / Дайын), клиент өз экранында көреді.
- Баға серверде қайта есептеледі, клиент бағаны өзгерте алмайды.

## Файлдар
- server.js: сервер (API, нақты уақыт, құпиясөз)
- public/index.html, client.js: клиент сайты
- public/admin.html: админ панель
- data/site.json: мәзір мен мәтіндер, data/orders.json: тапсырыстар (осы екі файлды резервке сақтаңыз)

## Интернетке шығару
Node.js жұмыс істейтін кез келген хостинг (VPS, Render, Railway) жарайды. HTTPS қосыңыз (Nginx/Caddy немесе хостингтің өзі).
Статикалық хостинг (GitHub Pages, Netlify) жарамайды, себебі сервер керек.

## Клиенттер базасы (тіркелу)
- Клиент сайтта "Кіру → Тіркелу" арқылы тіркеледі (аты, телефон, құпиясөз). Құпиясөз ашық сақталмайды (scrypt хэші).
- Админ панельде "Клиенттер" қойындысы: барлық клиенттер, іздеу, тапсырыс саны мен жиынтық сомасы, құпиясөзді жаңарту, жою, Excel/CSV жүктеу.
- "Баптаулар" ішінде "Тапсырыс беру үшін тіркелу міндетті" деген құсбелгі бар (қаласаңыз қосыңыз).
- Деректер data/users.json файлында. Оны (және data/orders.json) үнемі резервке көшіріп тұрыңыз.
- Телефон нөмірлерін жинағандықтан, Қазақстанның дербес деректер туралы заңын сақтаңыз: келісім құсбелгісі қойылған, деректерді үшінші жаққа бермеңіз.

## Төлем әдістері
- Клиент себетте төлем тәсілін таңдайды: қолма-қол, терминал (курьерде) немесе Kaspi аударым/QR.
- Админ панель → Баптаулар → "Төлем әдістері": әдістерді қосу/өшіру, мәтінін өзгерту, Kaspi телефоны, төлем сілтемесі, QR суреті.
- Kaspi төлемі: клиент тапсырыс жібереді, соманы аударады, "Төлем жасадым" басады. Админ Kaspi қосымшасында түскенін тексеріп, "Төлем расталды" басады, клиент экранында да жаңарады.
- Банк картасымен сайттың өзінде төлеу (автоматты эквайринг) үшін Kaspi Pay, Halyk, Freedom Pay немесе CloudPayments сияқты банкпен шарт жасасып, API кілттерін алу керек. Соны қосу кейін жасалады.

## Жеке кабинет және камера (тек тіркелгендерге)
- Тіркелген клиентке сайтта "Кабинет" бөлімі шығады: қазіргі тапсырыстың жолы (нақты уақытта), тапсырыс тарихы, "Қайталау" батырмасы және тікелей камера. Тіркелмегенге бұл бөлім мен камера сілтемесі мүлде жіберілмейді.
- Камера: админ → Баптаулар → "Тікелей камера". Ағын сілтемесі HLS (.m3u8), YouTube Live/плеер беті (iframe) немесе MJPEG болуы керек. RTSP (rtsp://) браузерде ашылмайды, оны HLS-ке айналдыру керек (мысалы go2rtc).
- Тіркелу әзірге SMS-растаусыз, яғни кез келген адам тіркеле алады. Қатаңырақ қорғау керек болса, SMS-растау немесе админ бекіту қосуға болады.

## SMS растау (тіркелу және құпиясөзді қалпына келтіру)
SMS қызметі қосылса, тіркелу екі қадамды болады: телефонға 6 таңбалы код келеді, код дұрыс болса ғана тіркеледі. "Құпиясөзді ұмыттым" да SMS арқылы жұмыс істейді.
Қызмет қосылмаса, тіркелу бұрынғыша (SMS-сыз) жұмыс істейді.

Кілттер тек сервердің орта айнымалыларында сақталады (сайтқа немесе админге жазылмайды):

| Қызмет | Айнымалылар |
|---|---|
| Mobizon (mobizon.kz) | SMS_PROVIDER=mobizon, MOBIZON_KEY=API-кілт (қосымша: SMS_SENDER, MOBIZON_HOST) |
| SMSC (smsc.kz) | SMS_PROVIDER=smsc, SMSC_LOGIN, SMSC_PASSWORD (қосымша: SMS_SENDER) |
| Сынақ (SMS жіберілмейді) | SMS_PROVIDER=console: код сервер терезесіне шығады |

Қосымша: SMS_DAILY_LIMIT=300 (күніне ең көп SMS, қателікті шығыннан қорғау).
Windows-та қолмен: терезеде `set SMS_PROVIDER=console` жазып, сосын `node server.js`. Render-де: Environment бөліміне осы айнымалыларды қосыңыз.
Қорғаныс: бір нөмірге 60 секундта бір рет, күніне 5 SMS; бір IP-ге сағатына 8; код 5 минут жарамды, 5 қате әрекеттен кейін бұғатталады.
