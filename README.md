# Big Doner: сайт + админ панель

Тек Node.js 18+ керек (npm install КЕРЕК ЕМЕС).

## Іске қосу
Windows: start.bat файлын екі рет басыңыз. Mac/Linux: терминалда ./start.sh

Немесе қолмен:
    ADMIN_PASSWORD=өзіңіздің_құпиясөз node server.js

- Клиент сайты: http://localhost:3000
- Админ панель: http://localhost:3000/admin
(ADMIN_PASSWORD көрсетпесеңіз, құпиясөз "admin123" болады. Міндетті түрде ауыстырыңыз!)
Порт өзгерту: PORT=8080

## Қалай жұмыс істейді
- Админ мәзірді, комбоны, бағаны, суретті, филиалды өзгертіп "Сайтқа сақтау" басады, ашық тұрған клиент беттері бірден жаңарады.
- Клиент тапсырыс бергенде админ панельде бірден шығады (дыбыспен). Админ статус ауыстырады (Қабылданды / Дайындалуда / Жолда / Дайын), клиент өз экранында көреді.
- Баға серверде қайта есептеледі, клиент бағаны өзгерте алмайды.

## Файлдар
- server.js: сервер (API, нақты уақыт, құпиясөз)
- public/index.html, client.js: клиент сайты
- public/admin.html: админ панель
- data/site.json: мәзір мен мәтіндер, data/orders.json: тапсырыстар (осы екі файлды резервке сақтаңыз)

## Интернетке шығару
Node.js жұмыс істейтін кез келген хостинг (VPS, Render, Railway) жарайды. HTTPS қосыңыз (Nginx/Caddy немесе хостингтің өзі).
Статикалық хостинг (GitHub Pages, Netlify) жарамайды, себебі сервер керек.

## Клиенттер базасы (тіркелу)
- Клиент сайтта "Кіру → Тіркелу" арқылы тіркеледі (аты, телефон, құпиясөз). Құпиясөз ашық сақталмайды (scrypt хэші).
- Админ панельде "Клиенттер" қойындысы: барлық клиенттер, іздеу, тапсырыс саны мен жиынтық сомасы, құпиясөзді жаңарту, жою, Excel/CSV жүктеу.
- "Баптаулар" ішінде "Тапсырыс беру үшін тіркелу міндетті" деген құсбелгі бар (қаласаңыз қосыңыз).
- Деректер data/users.json файлында. Оны (және data/orders.json) үнемі резервке көшіріп тұрыңыз.
- Телефон нөмірлерін жинағандықтан, Қазақстанның дербес деректер туралы заңын сақтаңыз: келісім құсбелгісі қойылған, деректерді үшінші жаққа бермеңіз.
